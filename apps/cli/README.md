# @borg0ai/reasongraph

ReasonGraph CLI for seeding repository decision history and installing the
ReasonGraph agent plugin.

```sh
npx --yes @borg0ai/reasongraph init
npx --yes @borg0ai/reasongraph install
```

`init` seeds `.reasongraph/` in the current repository. `install` adds the
repository-root ReasonGraph plugin through `npx plugins`.
